# Phase 22E — Opt-in persistent lexical index cache

Set `CODELOCAL_BETA_INDEX_CACHE=1` when starting a Rust beta CLI command or local stdio MCP server to enable caching for existing `symbol-search` and `dependency-map` queries. Default behavior remains uncached. Cache support is Unix-only; other platforms retain the original bounded scan. Single-file `source-index` is unchanged.

The cache is a versioned, atomic, private 0600 JSON snapshot in the beta state directory (`index-cache-v1.json`), capped at 4 MiB total, containing metadata and lexical declaration/import candidates but not source bodies. Only one workspace snapshot is retained; switching workspaces replaces it. Workspace ID, canonical root digest and grant timestamp bind reuse to the current grant. Each query still walks the current workspace, applies ignore and sensitive-path policy, opens bounded regular files without following symlinks, and hashes actual bytes before reusing any entry. Deleted/ignored/changed files cannot be returned merely because a cache entry exists. Existing scan and result caps are unchanged. Malformed, oversized and inaccessible caches fall back to live analysis. Cache statistics (`hits`, `misses`, `persisted`) appear under `scan.cache` when the optional private store is usable. The cache is trusted local user state, not a signed evidence store.

Run `codelocal index-cache-clear` to remove the fixed snapshot; stop concurrent cache-enabled queries first. Revoking a grant prevents subsequent access but does not automatically erase the snapshot; clear it explicitly if required. No Cloud synchronization, background indexing, LSP or semantic graph is provided. Rewalking and hashing remain necessary; this optimization avoids repeated lexical extraction, not all filesystem I/O. A fresh scan is not an atomic workspace snapshot under concurrent edits. No Windows ACL support is claimed.

Tests cover disabled-by-default behavior, cold/warm hits, same-length edits, gitignore changes, deletion, cache size/corruption, private file mode, workspace isolation, symlink safety and revoked grants. No Next.js, archived Go, production or main changes.
